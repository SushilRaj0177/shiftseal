# Shiftseal: a FairShift decent work platform (SDG 8)

**Every hour counted. Every rupee explained.**  
*Proof of work for the world's shift workers.*

> **Principle:** The AI understands. Code decides. Nothing reaches a worker unchecked.

## Overview

Shiftseal is a dual-interface decent work platform built for employee-intensive sectors (**Construction Sites** and **College Campus Facilities**). It combines multimodal Gemini AI extraction (voice and text in Tamil, Hindi, and English) with a deterministic, unit-tested verification layer and SHA-256 tamper-evident shift receipts.
